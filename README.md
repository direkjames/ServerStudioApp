# The Server Studio: Content Hub
Open `index.html` in Chrome. No install, no build. Data is stored in the browser (localStorage); use Settings > Export backup regularly.
Views: Today, Calendar & Board, Idea Bank, Scripts (ElevenLabs export), Shorts Planner, Analytics, Upload Checklist, Settings.
`data.js` holds the seed plan and 30 ideas; edit it, then Settings > Reset to reload the seed.
